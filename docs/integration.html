Integrar una herramienta

SHParro incluye interfaces estáticas mediante iframe. Cada herramienta conserva su HTML, CSS y JavaScript independientes.

1. Colocar los archivos

Agrega la aplicación dentro de Web/<nombre-herramienta>/. Debe tener un index.html accesible desde GitHub Pages.

2. Registrar la herramienta

Abre tools.json y añade un objeto. Ejemplo para una nueva herramienta:

{
  "id": "mi-herramienta",
  "name": "Mi herramienta",
  "shortName": "MH",
  "description": "Descripción breve de la herramienta.",
  "category": "Utilidades generales",
  "path": "./Web/MiHerramienta/index.html",
  "status": "available",
  "offline": false,
  "icon": "M"
}

Campos

CampoUso
idIdentificador único. Puede utilizarse en enlaces con #tool=id.
nameNombre completo mostrado en tarjetas y barra superior.
descriptionResumen corto mostrado en la tarjeta.
categoryAgrupa herramientas en la cuadrícula y en el menú lateral.
pathRuta relativa desde la raíz de SHParro.
statusavailable, requires, development o error.
offlineIndica que la herramienta fue preparada para funcionar sin conexión.
iconTexto corto o símbolo mostrado en la tarjeta.

3. Abrir directamente

Después de publicar el sitio, cualquier herramienta puede enlazarse así:

https://thecodingstudent.github.io/SHParro/#tool=tran-all

Qué es un iframe

Un iframe es una ventana HTML dentro de otra página. SHParro muestra cada herramienta dentro de esa ventana, aislando sus estilos y scripts. La herramienta puede seguir siendo instalada y usada en su URL original.

Limitaciones en GitHub Pages

  • GitHub Pages solo sirve archivos estáticos; no ejecuta Flask, Django ni Python.
  • Las interfaces deben funcionar con HTML, CSS y JavaScript del navegador.
  • Las APIs externas deben permitir CORS o proporcionar una solución JSONP/backend externa.
  • Los favoritos se guardan en localStorage del navegador.
  • Para ejecutar el sitio localmente usa un servidor HTTP, no abras index.html mediante file://.
